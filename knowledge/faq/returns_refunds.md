# Northstar Customer Support — FAQ Knowledge Base

## Order Status

### Where is my order?
Customers can ask for the current status of their order by providing a valid order number, for example `ORD-12345`.

### What order number should I provide?
Provide the order number shown on the customer's order confirmation. Northstar order numbers use the format `ORD-12345`.

### Can Northstar check my order without an order number?
No. The customer must provide their order number before Northstar can check the order status.

---

## Returns

### How do I return an item?
Northstar guides the customer through the return process and checks whether the item is eligible for return.

The return flow has four steps:

1. Confirm the order number.
2. Confirm the item and return reason.
3. Check whether the item is eligible for return.
4. Provide the next steps or escalate to human support when required.

### What happens if my return is eligible?
Northstar provides the customer with the next steps for completing the return.

### What happens if my return requires human review?
Northstar escalates the request to a human support representative.

---

## Refunds

### Where is my refund?
Customers should provide their order number so Northstar can check the refund status.

Example:

`Where is my refund?`

followed by:

`ORD-12345`

### How do I check a refund?
Provide the order number associated with the refund request.

### What happens if Northstar cannot resolve my refund issue?
The issue can be escalated to a human support representative.

---

## Human Support

### Can I talk to a human?
Yes. Customers can request human support at any time.

Example:

`I want to talk to a human`

Northstar creates an escalation response containing the escalation status and ticket ID.

### What happens after escalation?
The request is marked as escalated and a support ticket is created.

Example:

`TICKET-001`

---

## General Support

### What can Northstar help me with?
The MVP supports:

- Order status
- Returns
- Refunds
- Human support escalation

### What happens if Northstar does not understand my question?
Northstar asks the customer to rephrase the request or provides the appropriate next step.

### Does Northstar support every customer service request?
No. This is an MVP and only supports the workflows implemented for order status, returns, refunds, and human escalation.

---

## MVP Limitations

- Order status lookup is currently a stub/demo response.
- Refund processing is limited to the implemented MVP flow.
- Return eligibility is based on the rules implemented in the backend.
- Human escalation currently uses a demonstration ticket ID such as `TICKET-001`.
- Northstar does not connect to a live order-management or payment system in the MVP.
